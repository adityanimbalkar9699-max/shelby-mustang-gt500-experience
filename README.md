## 🌟 Executive Overview
This application is an **Apple-grade, real-time 3D WebGL automotive showcase & product reveal film** engineered for the **Shelby Mustang GT500 "Predator"**. Powered by **Three.js** and the **Web Audio API**, the experience features a **real 3D Shelby Mustang model** with physical clearcoat PBR shaders, studio turntable lighting, 360° orbital controls, **real mechanical opening parts (hood & doors)**, an **interactive 180 MPH track running animatic**, and an **Apple Keynote Cinematic Reveal Film**.

## 🚀 How to Run Locally
Start a local static server to serve the GLTF 3D model:
```powershell
# Using Python:
python -m http.server 8000
# Then open: http://localhost:8000
```
Or using Node.js:
```powershell
npx serve .
```
